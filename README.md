# Clickd

Greenfield Unity repository for **ClickDungeon**, a 2D tile-based dungeon crawler targeting Windows, Android, and iOS.

The player-facing product name is **ClickDungeon**. `ClickDungeon2` must not appear in shipping/player-facing UI.

This repository intentionally starts from scratch. The supplied reference images in `docs/reference/` are the primary product specification. The approved design lives at `docs/specs/clickdungeon-master-design.md`, and implementation is governed by Superpowers plans under `docs/superpowers/plans/`.

No gameplay implementation has been started yet. The next execution boundary is the approved Phase 0–1 foundation plan.
